Verantwortlicher

Verantwortlich für die Verarbeitung personenbezogener Daten auf dieser Website im Sinne der Datenschutz-Grundverordnung (DSGVO) ist Felix Mühlenberend, erreichbar per E-Mail an felix.muehlenberend@mailbox.org.

Hosting bei GitHub Pages

Diese Website besteht aus statischen Dateien und wird über GitHub Pages ausgeliefert, einen Dienst der GitHub, Inc. (USA). Wenn Sie eine Seite aufrufen, baut Ihr Browser eine Verbindung zu den Servern von GitHub auf. Dabei speichert GitHub nach eigenen Angaben Ihre IP-Adresse in Server-Logs, zu Sicherheitszwecken. Ich selbst erhalte diese Logs nicht und werte keine Daten über Besucher aus.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Mein berechtigtes Interesse ist, die Website sicher und zuverlässig bereitzustellen. Ohne die Verbindung zum Server kann keine Seite angezeigt werden.

GitHub kann die Daten in den USA verarbeiten. GitHub ist nach dem EU-US Data Privacy Framework zertifiziert, für das die EU-Kommission einen Angemessenheitsbeschluss erlassen hat (Art. 45 DSGVO). Wie lange GitHub die Logs aufbewahrt, legt GitHub fest. Einzelheiten stehen in der Datenschutzerklärung von GitHub.

Keine Cookies, kein Tracking

Diese Website setzt keine Cookies und nutzt auch keinen anderen Speicher in Ihrem Browser, etwa Local Storage. Sie speichert also keine Informationen auf Ihrem Gerät und liest dort keine aus. Eine Einwilligung nach § 25 TDDDG ist deshalb nicht nötig. Es gibt keine Analyse- oder Tracking-Werkzeuge.

Keine Inhalte von anderen Servern

Die Website lädt nichts von anderen Servern: keine Schriftarten, keine Skripte aus einem CDN, keine eingebetteten Inhalte. Texte erscheinen in den Schriftarten Ihres Geräts. Videos und PDFs liegen bei den übrigen Dateien dieser Website.

Links zu anderen Websites

Die Seiten enthalten Links zu anderen Websites, etwa zu GitHub, LinkedIn, dem KIT, der UPC oder itch.io. Das sind einfache Links. Erst wenn Sie einen davon anklicken, ruft Ihr Browser die andere Website auf. Für die Datenverarbeitung dort ist deren Betreiber verantwortlich.

Kontakt per E-Mail

Wenn Sie mir eine E-Mail schreiben, verwende ich Ihre Adresse und den Inhalt der Nachricht nur, um Ihnen zu antworten. Ich gebe sie nicht weiter. Die Nachrichten liegen bei meinem E-Mail-Anbieter mailbox.org. Ich lösche sie, wenn sie für den weiteren Austausch nicht mehr gebraucht werden.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. b DSGVO, wenn Ihre Nachricht eine Bewerbung oder eine Stelle betrifft, sonst Art. 6 Abs. 1 lit. f DSGVO (mein Interesse, Anfragen zu beantworten).

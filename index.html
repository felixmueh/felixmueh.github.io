I'm a computer scientist in Karlsruhe (M.Sc. Computer Science, KIT). For my master's thesis I ported a recent open-source GPU trajectory optimiser to an embedded GPU and ran it on a real robot arm. The work led directly to improvements upstream. Before that I spent two years as a working student at Mercedes-Benz, where I conceived and built a Python framework that lets engineers automate their finite-element simulations, working in a small team. For my bachelor's thesis I coupled a type system with the theorem prover KeY.

I'm looking for a full-time position and can start now.

GPU-accelerated MPC on a real robot arm

Master's thesis, KIT · 2026
  • CUDA/C++
  • Python
  • ROS 2
  • NVIDIA Jetson AGX Orin
project page thesis PDF (7.6 MB) merged GATO PRs tiago_mpc (code) MPCGPU study (code)

I ported the GPU trajectory optimiser GATO to the right arm of a TIAGo Pro and ran it as a model predictive controller on the robot's embedded NVIDIA Jetson AGX Orin, in simulation and on the physical arm. Solve times allow about 150 control updates per second, and three fixes I found along the way were merged into GATO.

Type system meets theorem prover

Bachelor's thesis, KIT · 2023
  • Java
  • Checker Framework
  • JML
  • KeY
code thesis PDF (0.8 MB)

Information-flow control for Java: the type checker SFlow checks most methods automatically and generates JML contracts for the theorem prover KeY where it fails. I extended the type system with rules for implicit flows and method types and proved the combined system sound.

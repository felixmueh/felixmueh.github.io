I'm a computer scientist in Karlsruhe (M.Sc. Computer Science, KIT). For my master's thesis I ported a recent open-source GPU trajectory optimiser to an embedded GPU and evaluated it in simulation and on a real robot arm. The work led directly to upstream improvements.

Before that I spent two years as a working student at Mercedes-Benz, where I conceived and built a Python framework that lets simulation engineers write their own finite-element automations. I'm also interested in programming languages. My bachelor's thesis coupled a type system for secure information flow with the theorem prover KeY, and in my own time I built dice, a small language for exact dice probabilities, and mima-c, a C compiler for KIT's teaching CPU.

I'm looking for a full-time position and can start now.

Type system meets theorem prover

Bachelor's thesis, KIT · 2023
  • formal verification
  • type systems
  • Java
  • KeY
  • JML
  • static analysis
code thesis PDF (0.8 MB)

Information-flow control for Java: the type checker SFlow checks most methods automatically and generates JML contracts for the theorem prover KeY where it fails. I extended the type system with rules for implicit flows and method types and proved the combined system sound.
